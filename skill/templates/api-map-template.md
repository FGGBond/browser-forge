# 接口依赖链

## 调用顺序

1. `{HTTP方法} {path}` → 获取 `{输出字段}`（下一步必需）
2. `{HTTP方法} {path}` → 输入 `{上一步字段}` → 获取 `{输出字段}`

## 数据流

```
[用户输入] {inputField}
     │
     ▼
{HTTP方法} {path1}  →  {中间字段}
     │
     ├─→ {HTTP方法} {path2}  →  {另一字段}
     │
     ▼
{HTTP方法} {最终接口}
  输入: { {中间字段}, {另一字段} }
     │
     ▼
[输出] {最终产物字段}
```

| 凭证字段 | 来源接口 | 传递方式 | 生命周期 | auth.sh 中处理方式 |
|---------|---------|---------|---------|-----------------|
| {字段名} | `{接口路径}` | header/cookie/body | {有效期} | 自动获取，不暴露给用户 |
